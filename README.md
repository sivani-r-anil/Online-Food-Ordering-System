# 🍔 Online Food Ordering System

A web-based Online Food Ordering System that allows users to browse restaurants, view menus, place food orders, and manage their accounts through a simple and user-friendly interface.

## 📌 Features

### User
- User Registration and Login
- Browse Restaurants
- View Food Menu
- Add Items to Cart
- Place Orders
- View Order History
- Logout

### Admin
- Admin Login
- Manage Restaurants
- Manage Food Items
- View Customer Orders
- Update Order Status
- Delete Orders

## 🛠️ Technologies Used

- PHP
- HTML5
- CSS3
- JavaScript
- Bootstrap
- MySQL
- XAMPP (Apache & MySQL)
